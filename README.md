# DIWEB-2026-02

Projetos do curso de DIWEB-I, do segundo semestre de 2026, em HTML e CSS do curso de Técnico em Informática
Escola Técnica de Ceilândia.

# Descrição

Nesse repositório serão disponibilizados os exercícios realizados durante o curso. Os exercícios estarão armazenados em diretórios divididos em unidades. Onde cada uma delas conterá sub-diretórios representando as aulas.

# Tecnologias

Aprenderemos nesse semestre a construir páginas em HTML e CSS. Para armazenar essas páginas utilizaremos o maior repositório de código aberto existente na WEB. O GitHub. Para documentar usaremos arquivos na linguagem Markdown em arquivos README.md. Por fim, testaremos nossas páginas utilizando GitHub Pages.
